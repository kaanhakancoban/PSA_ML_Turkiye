# Pre-publication checklist

- [ ] Confirm exact article title, full author list and DOI.
- [ ] Insert preferred public contact email in README and MODEL_REQUEST.
- [ ] Upload real GUI screenshots.
- [ ] Review and add MATLAB GUI source.
- [ ] Test GUI with the trained model files locally.
- [ ] Confirm software redistribution permissions for the GUI.
- [ ] Decide and add an explicit software license if public reuse is intended.
- [ ] Verify no trained models, copyrighted source datasets or private information are committed.
- [ ] Publish the GitHub repository as Public.
